## 待真实需求确认的基础能力

以下能力暂不预建，避免 `shared/lib` 变成猜测性的工具集合；出现首个明确页面或功能需求时，再各自独立立项、建目录、补测试和文档：

- [ ] URL 查询状态：确有筛选条件、分页、排序或 Tab 需要与地址栏同步时再建立 `shared/lib/query-state`；资源 ID 必须保持在语义化路径参数中，不能放入查询参数。
- [ ] 快捷键：确认存在跨页面的桌面快捷键需求与冲突策略后，再建立 `shared/lib/keyboard`。
- [ ] 通知 UI：在 `shared/notification` 内实现定制 Provider、队列、位置、关闭交互和 `tld-` 样式组件，替换当前原生对话框回退；不得改变业务侧 `notification` 调用入口，也不提前绑定第三方 UI 库。
- [ ] 交易日历/交易时段：属于市场或交易所领域，不进入 `shared/lib`；应在对应 `entities` 中按市场规则实现。
